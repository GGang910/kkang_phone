# 📱 깡폰 (kkang_phone)

**SillyTavern 확장 — 롤플레이 속 세계관 안에서 굴러가는 가상 스마트폰.**

현재 채팅(롤플레이) 맥락을 기반으로, 폰 안에서 메신저·통화·SNS·라이브 방송을 굴립니다. UI와 생성 출력의 기본 언어는 한국어입니다.

---

## ✨ 주요 기능

| | |
|---|---|
| 💬 **메신저** | DM·그룹챗, 이모티콘/스티커, 사진·기프티콘·위치·약속 전송. NPC가 성격대로 답장(여러 통 분할 포함). |
| 📞 **통화** | 수신·발신 통화, 대사 자막 애니메이션. |
| 🐦 **트위터(X)** / 📸 **인스타** | 현재 상황에 대한 사람들의 반응 피드, 좋아요·리트윗·댓글, 내 글 작성·내 프로필. |
| 🕵️ **블라인드** / 🎓 **에브리타임** | 직장인·대학생 익명 커뮤니티 글·댓글·대댓글. |
| 📺 **라이브 방송** | 방송 화면(AI 이미지)·실시간 채팅·시청자/호스트 반응, 2인 합방. |
| 🔒 **OnlyFans** | 구독·PPV·후원, 지출 내역 원장. |
| 🎨 **AI 이미지 생성** | 사진 전송·SNS 사진을 장면에 맞춰 생성. 인물 외형 태그를 카드/월드인포에서 자동 추출, 장면에 맞춰 의상 적응. |
| 📚 **월드인포 인식** | 연결된 월드인포에서 인물 외형·말투·세계관을 읽어옴(시뮬봇·다인봇 대응). SNS는 세계관 전체 자동 인식. |
| 🌍 **세계관 모드** | **이입**(세계 시민 반응) / **독자**(이 채팅을 웹소설처럼 보는 제3자) + 폰 지역·언어 직접 설정. |
| 🔔 **먼저 연락** | NPC가 채팅 흐름·확률에 따라 먼저 DM·전화. 폰을 닫아둬도 채팅 화면 위로 알림. |
| 🎨 **폰꾸** | 라이트/다크 테마, 텍스트 가리기(단어 치환). |
| 💾 **데이터** | 챗별 저장 / 캐릭터 공용 저장, JSON 백업·복원, 항목별·공장 초기화. |

## 📥 설치

SillyTavern → **확장 프로그램 → Install extension** → 아래 URL 입력:

```
https://github.com/GGang910/kkang_phone
```

설치 후 채팅 화면의 **햄버거(☰) 확장 메뉴**에서 **깡폰**을 열고, 가운데 빨간 전원 버튼으로 켭니다. (요술봉🪄 메뉴 아님)

### 요구 사항
- 최신 SillyTavern 권장(구버전은 자동 폴백으로 동작하나 토큰 비용↑).
- **Chat Completion** 계열 API에서 가장 잘 동작합니다.
- AI 이미지 생성은 ST 내장 Image Generation(`/sd`) 설정이 필요합니다(NAI 권장). 미설정 시 그 기능만 비활성.

## 💸 토큰 비용 (중요)

폰은 메인 채팅과 **별도로** 모델을 호출합니다. 비용을 크게 줄이도록 설계돼 있습니다.

- 기본값 **[💸 경량 호출] ON** — 폰 호출에 메인 프리셋·전체 채팅을 동봉하지 않습니다.
- 폰 설정 → **[🔌 폰 전용 연결 프로필]** 지정을 강력 권장. 폰 호출이 그 프로필로 **완전 격리**되어 메인 RP와 다른(저렴한) 모델을 쓸 수 있습니다. (안 고르면 지금 메인이 쓰는 연결을 그대로 따라감)
- **[📜 채팅 인지량]** 슬라이더로 폰 NPC가 참고하는 최근 채팅 분량을 조절(적게 줄수록 더 가벼움).
- **[📚 월드인포 참조]** 는 기본 OFF — 인물 정보가 월드인포에 든 다인봇·시뮬봇에서만 켜세요(켜면 SNS가 세계관 전체를 인식, 분량은 슬라이더로 조절). 주입깊이(@Depth)로 넣은 상태창·선택지 같은 지시문은 자동 제외됩니다.

## 🐞 문제 제보

설정 맨 아래 **버전 줄(📱 깡폰 vX.Y.Z)** 을 탭하면 **디버그 로그** 화면이 열립니다. "안 됨" 제보 시 이 화면의 복사본을 함께 주시면 원인 파악이 빠릅니다.

## 🗑️ 삭제 시 주의

ST UI에서 "삭제"를 눌렀는데 **`kkang_phone` 폴더가 남아 있으면** 탐색기(또는 PowerShell)로 직접 삭제하세요.

```powershell
Remove-Item -Recurse -Force "...\SillyTavern\data\default-user\extensions\kkang_phone"
```

> git으로 설치된 확장은 `.git/objects/` 안 파일이 읽기전용이라 ST 삭제가 실패하는 경우가 있습니다(ST 공통 현상).
